# Демо-разметка для воспроизводимой оценки

**Метрики измеряются на синтетическом демо-наборе с известной разметкой,
а не на независимой разметке врача. Это ограничение: числа не подтверждают
качество на реальных пациентах и новых клинических данных.**

Уточнение происхождения: `scripts/make_demo_data.py` сохраняет клинический
текст исходных DOCX хакатона, заменяя идентификаторы синтетическими.
GOLD содержит заранее записанные метки по заключениям; генератор не подсаживает
GOLD в тексты. Поэтому набор синтетический по идентификаторам, но не полностью
искусственный по клиническому содержанию. Независимая врачебная валидация
GOLD в репозитории не подтверждена. Ожидаемые ответы не получены от оцениваемого
экстрактора, однако набор фиксированный и использовался при разработке:
это не независимый тест обобщения.

`labeled.json` содержит 204 пары для 79 исследований: только `study_id`,
`trigger_id`, булеву метку и историческое имя split `gold`. ФИО, дат,
номеров карт, телефонов и текстов пациентов в разметке нет.
Метки детерминированно получаются через `build_labels()` из GOLD и
`config/routing_matrix_legacy.json`; новые категории матрицы врача здесь
не размечены и в метриках исключены.

Из корня свежей копии репозитория:

```bash
env -u PYTHONPATH -u VIRTUAL_ENV uv run python scripts/evaluate_extraction.py
```

База данных, сервер и исходные DOCX не требуются. Оценщик читает файл разметки
из репозитория; отсутствие файла является ошибкой.

Перегенерация только разметки без исходных DOCX:

```bash
env -u PYTHONPATH -u VIRTUAL_ENV uv run python -m scripts.generate_demo_labels
```

Порядок записей, UTF-8, отступы и завершающий перевод строки фиксированы;
тест сравнивает результат с опубликованным файлом побайтово.
Полный генератор `make_demo_data.py` требует исходные DOCX и использует текущую
матрицу; его результат не заменяет эту оценку по историческим категориям.

`protocols.manifest` фиксирует SHA-256 каждого из 89 протоколов и ожидаемые
пары разметки. Для 10 протоколов простаты явно указана причина исключения:
в исходной матрице нет категории. Они проверяются на наличие и изменение,
но не входят в знаменатели метрик. При изменении набора нужно проверить
тексты и метки, затем осознанно обновить манифест; перегенерация разметки
не обновляет хеши автоматически. Оценщик и тест отказываются считать метрики
при добавлении, удалении или изменении протокола и потере любой пары разметки.
